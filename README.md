# CodeAlpha_ImageGallery

A modern and responsive Image Gallery built with HTML, CSS, and JavaScript. This project provides an interactive and visually appealing way to browse images with smooth animations and user-friendly navigation.

Features

1. Responsive Layout: Adapts to desktop, tablet, and mobile screens.
2. Image Navigation: Easily browse images using Next and Previous buttons.
3. Lightbox View: Display images in an enlarged overlay.
4. Hover Effects: Interactive image effects for a better user experience.
5. Smooth Transitions: Seamless animations while browsing images.
6. Clean UI: Simple, modern, and user-friendly design.

Technologies Used

HTML5
CSS3
JavaScript

 Project Objective

To create an interactive, responsive image gallery while practicing frontend development, CSS layouts, JavaScript navigation, and UI design.
